## Proposed Changes

### 1) 导出第 5 页快照：以 `roof-editor-grid` 的画布全区尺寸为准，统一尺寸来源与注入尺寸

**目标**

- 导出快照的像素尺寸 == 画布在第 5 页上看到的区域尺寸（包含标尺/网格/viewport）。
- 注入到 PDF clone 后不裁切、不缩放错位。

**实现**

- 生成快照时使用：
  - `grid.getBoundingClientRect()` 为主
  - 若宽高异常（例如 0 或过小），fallback `grid.offsetWidth/offsetHeight`
  - 记录最终 `w0/h0` 并在 onclone 注入时给 clone 的 `#roof-editor-grid` 强制设置 `style.width/height` 为同样的像素值（避免 clone 布局差异导致裁切）。
- 注入方式从“absolute 填充 + overflow-hidden”调整为：
  - `grid.style.overflow = 'visible'`（仅 clone 内）
  - `<img>` 采用 `display:block; width:100%; height:auto;` 并让 grid 自身维持固定高度（或 `<img>` 设 `height:100%` + `objectFit:contain`，但必须确保 grid 有明确高度）。

### 2) 自定义组件：导出必须按顶点编辑后的 `m.points` 绘制（不允许退化为矩形）

**目标**

- type=custom 且存在 `m.points.length>=3` 时，始终用 points 绘制 polygon。
- points 的坐标映射与编辑器一致（与 `worldToPx()` 同一屋顶坐标系、同一 `pxPerM`）。

**实现**

- 导出绘制 modules 时：
  - 对 custom：不使用 `getModuleDimsM()` 决定形状，改为：
    - 若 `m.points` 存在：直接用 points
    - 否则才 fallback `getCustomShapePointsFromRect()`
  - points->px：使用与标注同样的 `worldToPxExport()`。

### 3) 测距线/面积多边形：改为“严格复刻 renderRoofMeasurements 的几何与样式”，并增加可视性兜底

**目标**

- dist：线段 + 端点 marker/arrow 必须可见
- area：fill + stroke 必须可见
- 数字保持黑色胶囊样式

**实现**

- 直接复刻 [renderRoofMeasurements](file:///Users/jqz/Library/CloudStorage/OneDrive-个人/Github%20Project/minova/index.html#L11250-L11360) 的渲染顺序与颜色选择：
  - dist 使用 `m.color || settings.distColor`，stroke alpha 统一为 0.95，lineWidth 统一为 2（考虑到导出 scale，会更清晰）
  - area 使用 `m.bgColor/settings.areaDefaultBgColor` + `opacity`，stroke 固定 `rgba(88,44,131,0.95)`
- 增加兜底可视性：
  - 如果 `pxPerM` 异常（过小/过大），将 `pxPerM` clamp 到合理范围（例如 0.5~500）并记录到导出日志（仅 console，不写注释）
  - 若某条 dist 的屏幕长度 < 1px，强制绘制一个最短可见线段（避免因为极端缩放导致“看起来没线”）

### 4) 背景图比例：确保 “完整展现上传图” 与编辑器一致

**目标**

- 背景图在导出快照中使用与编辑器一致的 contain 算法与左上对齐，且绘制区域不超出 viewport。

**实现**

- 使用 `img.naturalWidth/naturalHeight` 与 viewport w/h 计算 contain 的 `bgRect.w/h`，x/y=0（左上）。
- 绘制背景时严格使用 `ctx.drawImage(img, vp.x + bgRect.x, vp.y + bgRect.y, bgRect.w, bgRect.h)`。

### 5) 仅影响导出第 5 页：保持其它页面与正常使用不受影响

- 所有改动限定在：
  - `confirmAndGeneratePDF` 的 pageNum===5 分支（生成快照 & 设置注入参数）
  - `opt.html2canvas.onclone` 的 useRoofSnap 分支（只改 clone DOM）
- 导出后清理 `window.__pdfExportingPageNum/__pdfRoofSnapshotDataUrl`，不污染后续导出。

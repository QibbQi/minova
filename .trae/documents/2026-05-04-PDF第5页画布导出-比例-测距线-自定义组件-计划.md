## Proposed Changes

### 1) 快照范围改为“viewport 级别合成”，避免 grid 尺寸与 PDF 布局导致比例偏差

**动机**

`#roof-editor-grid` 包含 20px 标尺边与内部 viewport，导出时页面宽度（mm）与屏幕像素布局不同，容易引入缩放与留白差异，从而使背景图比例“看起来不一致”。

**调整**

- `buildRoofSnapshotForPdf()` 的捕获目标从 `#roof-editor-grid` 改为 `#roof-viewport`（仅画布区域），并在快照里合成需要的元素：
  - 背景图（#roof-image）
  - 网格（#roof-grid-layer）
  - 模块层（#roof-modules-layer）
  - 标注层（#roof-measure-layer：线与面）
  - 标注数字（measure label 的 HTML，若它在 measure-layer 内则一并捕获；若不在，则临时复制到合成容器）
- 注入 PDF clone 时：
  - 将 clone 内 `#roof-viewport` 替换为 `<img src=snapshot>`，而不是替换整个 `#roof-editor-grid`。
  - 如需保留标尺边（可选），标尺仍用原 DOM；如果不需要则隐藏标尺边并让 viewport 位图占满导出区域。

### 2) 测距线/面积多边形：改为“SVG 位图化确保加载完成”，并补齐 SVG 序列化信息

**问题点**

当前 svg→img(data:image/svg+xml) 没有等待 img onload，且 svg 序列化可能缺少：
- `width/height`（某些解码器需要）
- `xmlns:xlink`（如用到 marker/defs）
- CSS 样式（stroke-dasharray、opacity 等）若来自内联 style 以外

**调整**

- 在离屏 clone 中：
  - 给 measure svg 强制补齐 `xmlns`、`width/height` 与 `viewBox`（以 viewport 像素为准）。
  - `XMLSerializer` 后，把 svg 内容封装到 blob URL（`URL.createObjectURL(new Blob([xml], {type:'image/svg+xml'}))`）而不是 dataURL，提升兼容性（并在 finally 里 revoke）。
  - 替换为 `<img>` 后 **等待 onload** 再进入 html2canvas。
- 若仍不稳定：提供兜底策略（同一函数内可开关）
  - 直接在 canvas 上用 2D context 绘制 dist/area（根据 `siteOverview.measurements` 与现有 worldToPx 计算），保证线与面一定存在（不依赖 SVG 兼容性）。

### 3) 自定义组件形状：在离屏 clone 中完整复现 shape 的 fill/stroke/alpha

**问题点**

当前仅对 `.pv-module-shape` 做 polygon→svg，但：
- fill 读取 computedStyle.backgroundColor 可能为 transparent（实际填充来自 `style.background`）
- border 读取边框颜色/宽度不一定正确
- drop-shadow（用于选中高亮）在导出时可以忽略或统一关闭，避免渲染差异

**调整**

- 解析 `.pv-module-shape` 的样式时优先读取：
  - `shape.style.background`（若是 rgba/hex，解析为 fill）
  - fallback 再用 computedStyle.backgroundColor
  - stroke 使用 `shape.style.border` 或 computedStyle.borderTopColor/borderTopWidth
- 生成 SVG 时：
  - `viewBox="0 0 100 100" preserveAspectRatio="none"`
  - `<polygon fill=... stroke=... stroke-width=... vector-effect="non-scaling-stroke">`
- 在离屏 clone 中统一移除 shape 的 `filter`（drop-shadow），减少 html2canvas 的 filter 兼容风险。

### 4) 不影响其他页面/不影响工具：所有改动严格限定在“导出离屏 clone + onclone clone”

- `buildRoofSnapshotForPdf()` 只操作离屏 clone（临时 host），绝不修改真实画布 DOM。
- `onclone` 只操作 clonedDoc（导出 clone），绝不修改真实 DOM。
- 导出结束后清空 `window.__pdfExportingPageNum / window.__pdfRoofSnapshotDataUrl`，并释放 blob URLs。

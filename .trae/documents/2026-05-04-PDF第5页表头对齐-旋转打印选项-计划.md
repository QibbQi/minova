- 在 `confirmAndGeneratePDF()` 开始生成前，从 modal 读取：
  - `const rotateSO = !!document.getElementById('qa-rotate-siteoverview')?.checked`
- rotateSO 只作为本次导出局部变量使用（不改变页面状态）；如需记忆偏好，再考虑 localStorage（本计划默认不持久化，避免影响）。

#### 2.3 导出：第 5 页画布快照按需旋转绘制（不超过页面）

**实现位置**：`pageNum===5` 的 PDFLib `drawImage` 部分

- 引入 PDFLib 的 `degrees`：
  - `const degrees = PDFLibRef.degrees;`（与当前已用的 `rgb/StandardFonts` 同级缓存）
- 当 rotateSO=false：沿用现有绘制逻辑
- 当 rotateSO=true：仅旋转“画布快照图片”，表头不旋转：
  - 使用 clockwise 90°：`rotate: degrees(-90)`
  - fit 计算时使用交换后的边界：
    - `ratio = min(pw / imgH, availH / imgW)`
    - `w = imgW * ratio`，`h = imgH * ratio`
    - 旋转后占用的 bounding box 为 `h x w`
  - 位置计算（保证不超出“表头下方可用区域”）：
    - 设可用区域为 `[0,pw] x [padBottom, padBottom+availH]`
    - `x = (pw - h) / 2`
    - `yTop = padBottom + (availH + w) / 2`
    - `page.drawImage(img, { x, y: yTop, width: w, height: h, rotate: degrees(-90) })`
      - 因为 -90° 绕 (x,y) 旋转后图像会落在 `y-w .. y`，上述 yTop 让其在可用区域内居中。

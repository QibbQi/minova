# 报价单样式与排版改进计划 (Quotation Layout Improvement Plan)

## 1. 目标 (Summary)
根据您上传的专业报价单图片，对比目前 `index.html` 中的报价生成页，提取出排版、样式和字段的差异，并提出 4 项改进建议。本计划旨在将目前的网页排版向您提供的图片格式靠拢，使其看起来更专业。

请您仔细查看以下 4 项建议，如果您同意全部修改，请点击“同意（Approve）”；如果您只希望修改其中的某几项，请拒绝并告诉我保留哪些建议，我将为您重新调整计划。

## 2. 当前状态与对比分析 (Current State Analysis)
目前网页中的报价单在排版上偏向于内部系统表单（例如左侧紫边框的客户信息、底部的系统规模等），而您提供的图片采用了更为紧凑、专业的商业信函/表格排版格式。
主要的差异点在于：页眉元素的分布、客户信息的背景块样式、时间表与支付条款的并排方式，以及表格底部税费（SST）的呈现。

## 3. 拟定的改进建议 (Proposed Changes)

### 建议一：页眉布局重构 (Header Layout)
- **现状**：Logo 在左上角，公司地址紧随其后；“报价单”标题、编号、日期在右上角。
- **改进**：
  - **左上角**：放置公司全称（`MINOVA HOLDINGS SDN. BHD. (1654564-U)`）以及办公地址。
  - **右上角**：放置横向的 `logo-horizontal.png`，下方紧跟紫色的 `Customer Quotation` 标题。
  - **标题下方**：右对齐放置 Date (日期) 和 Quotation Ref. No. (单据编号)。

### 建议二：客户信息区块样式升级 (Customer Info Block)
- **现状**：带有紫色左边框的简单输入行（包含客户公司、联系人、现场地址）。
- **改进**：
  - 采用图片中的**淡蓝色背景块**（如 `bg-blue-100` 或 `bg-slate-200`）。
  - 字段统一修改为左右两列对齐的格式（左侧加粗标签，右侧输入框）：
    - `Attention` (联系人) : `[输入框]`
    - `Contact No` (联系电话) : `[输入框]`
    - `Email Address` (邮箱) : `[输入框]`
    - `Address` (地址) : `[多行输入框]`

### 建议三：系统规模、时间表与支付条款重排 (Timeline & Payment)
- **现状**：时间表（Step 1-3）和支付条款并排在表格上方，而“Proposed System Size”在页面较下方。
- **改进**：
  - 在客户信息下方，优先显示 `Proposed System Size`（系统规模）及容量输入框。
  - 下方分为左右两列排版：
    - **左侧**：时间表（Step 1-3），采用图片中带淡色背景（如 `bg-indigo-100`）的整齐区块。
    - **右侧**：支付条款（Payment Term），将各项支付比例（如 10%、50%、35%、5%）的描述与对应的金额（RM）紧凑且右对齐排列。

### 建议四：报价明细表与税费合计优化 (Table & Totals)
- **现状**：表头包含产品、品牌、规格型号等；底部仅有“运输与装卸”和“应付总额”。
- **改进**：
  - **表头微调**：将部分列名调整为英文以贴近图片（如 `Item`, `Description`, `Brand`, `Rating`, `Quantity`, `Total Rating`, `Amount`）。
  - **表格底部汇总区**：
    - 增加 `Sub-total` (小计) 行。
    - 增加 `SST (6%)` 税费行（由小计乘以 6% 自动计算得出）。
    - 最终的 `Grand Total` 显示为图片中的品红色大号字体，并在下方增加一行红色的拼写金额（目前可作为输入框让用户手动填入大写拼写）。

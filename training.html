01 Workflow

先记住一条主线

大多数同事只要按这个顺序操作，就能完成标准报价。Most users can finish a standard quotation by following this flow.

打开网页并确认同步状态 / Open the page and check sync

进入 index.html 后先看右上角 GitHub 状态。显示未连接时，可以先做本地培训；正式保存或发布前再连接同步。

After opening index.html, check the GitHub status on the top right. Training can continue offline, but publishing needs sync connected.

确认语言与币种 / Confirm language and currency

用“中 / EN”切换页面文字，用“¥ / RM”切换显示币种。给客户看的报价通常用 RM，内部核算常看 ¥。

Use “中 / EN” for language and “¥ / RM” for currency. Customer quotations usually use RM; internal costing often uses RMB.

从库存或产品选择报价项目 / Add quote items from inventory or products

优先选库存中已有批次，因为库存带有采购成本、税费、运费和可销售价格。没有库存时，再手动新增空白行。

Pick existing inventory first because it carries cost, tax, freight, and selling price information. Use blank rows only when needed.

检查报价页面 1 到 5 / Review pages 1 to 5

报价单、财务分析、部件清单与质保、参考信息、Site Overview 都要看一遍。不要只看第一页。

Review Quotation, Financial Analysis, Part Breakdown & Warranty, Reference, and Site Overview. Do not check only page one.

保存报价并生成 PDF / Save and export PDF

先用“保存”保留报价记录，再点“生成报价（PDF）”。导出前确认客户名、地址、报价有效期、付款条款和附件。

Save the quote record first, then click “Generate Quotation (PDF)”. Check customer, address, validity, payment terms, and attachments before export.

03 Quotation

报价单怎么做

把它当成“填客户信息、选方案、加产品、检查页面、导出 PDF”的五步。

页面 1：报价单 / Page 1: Quotation

填写客户公司、现场地址、报价日期、有效期和付款条款。选择 Solar Program 后，系统会按不同方案显示相关内容。

Fill customer, site address, quote date, validity, and payment terms. Choose the Solar Program to match the project type.

添加产品 / Add products

从库存价格按钮选择产品最稳妥。数量可以自动带出，也可以点击数量单元格手动确认修改。

Adding from inventory price buttons is safest. Quantity can be automatic or manually confirmed from the quantity cell.

页面 2：财务分析 / Page 2: Financial Analysis

用于展示节省、电费、回本周期和 10 年 / 25 年收益。培训时提醒同事：这些数字要先核对项目参数。

Shows savings, tariff, payback, and 10-year / 25-year returns. Always verify project inputs before sharing numbers.

页面 5：Site Overview

可以上传屋顶图、添加 PV 组件、旋转/复制/删除组件，并做现场示意。适合屋顶或安装方案展示。

Upload a roof image, add PV modules, rotate/copy/delete modules, and create a site layout for installation discussion.

培训口径 / Training wording: 先保存报价，再导出 PDF。保存是为了以后能加载和修改；PDF 是发给客户的文件。Save first for future editing; export PDF for customer delivery.
04 Data

产品、库存、运输与认证

这些模块影响报价准确性。These modules decide whether the quote is accurate.

模块 / Module 什么时候用 / When to use 关键注意事项 / Key reminder
产品清单 / Products 新增产品、维护型号、供应商、图片、规格书和认证文件。 产品编号、类目、子类目和供应商要统一，否则库存和报价不容易匹配。
库存管理 / Inventory 产品入库、销售出库、修改库存价格、查看历史库存。 入库时认真填采购价、数量、税率、运费和存放位置；出库会影响可用库存。
运输管理 / Transport 从库存勾选货物生成运输单，记录货运公司、方式、运费、重量和体积。 运输状态要及时更新：草稿、运输中、已到货、已取消。
认证附件 / Certificates 报价 PDF 需要附带 ISO、产品认证、规格书或运输附件时使用。 导出 PDF 前在附件弹窗勾选需要的页面，不需要的不要勾。
GitHub 同步 / GitHub Sync 多人共用同一份数据，或需要发布到 GitHub Pages 时使用。 正式改数据前确认同步正常；遇到冲突先看提示，不要重复点击。
05 Settings

报价设置不是每天都改

利润和汇率会影响所有报价，培训时要强调权限和复核。Profit and exchange rate affect all quotes, so changes need review.

汇率 / Exchange rate

用于人民币成本和马币报价的换算。正式报价前请确认是否使用最新汇率。

Used for RMB cost to RM quotation conversion. Confirm the rate before issuing formal quotes.

利润设置 / Profit rules

可按公司主体、家用/工商业、类目和子类目设置利润。普通销售不建议随意修改。

Profit can be configured by company, home/C&I, category, and subcategory. Sales users should not change it casually.

安装费用 / Installation cost

海外施工费、国内施工费等可以加入报价单。加入前确认项目范围是否包含安装。

Installation options can be added to the quote. Confirm whether the project scope includes installation.

06 PDF Export

发客户前的最后检查

PDF 是客户看到的版本。导出前多花一分钟，能少很多返工。

07 Practice

建议培训练习

让同事真正点一遍，比只听讲更有效。Hands-on practice works better than only watching.

练习 1：生成一份简单报价 / Create a simple quote

输入一个模拟客户，选择 On-Grid System，从库存选择 2 到 3 个产品，检查总价。

Enter a demo customer, choose On-Grid System, add 2 to 3 inventory products, and review the total.

练习 2：保存和重新加载 / Save and reload

把报价保存为“Training Demo - 姓名”，切换到新报价后再加载回来。

Save as “Training Demo - Name”, switch to a new quote, then load it again.

练习 3：导出前检查 / Pre-export review

逐页查看 1 到 5 页，勾选需要的附件，生成 PDF 前口头复述检查清单。

Review pages 1 to 5, select needed attachments, and read the checklist before export.

练习 4：数据维护演示 / Data maintenance demo

由管理员演示产品清单、库存入库、销售出库和运输单，不建议所有新人直接修改正式数据。

An admin demonstrates products, inbound stock, outbound stock, and transport records. New users should not edit live data immediately.

常见问题 / Common issue: 如果页面看起来没有更新，先刷新浏览器；如果保存失败，检查 GitHub 是否连接；如果 PDF 排版不对，回到报价页逐页检查文字是否过长。
